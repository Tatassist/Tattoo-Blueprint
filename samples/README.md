# Tattoo Blueprint Sample Deliverables

These are fictional launch samples built to demonstrate the transformation Tattoo Blueprint provides.

They are not templates and they are not real client records. Each sample starts with a believable messy client idea, then shows the finished deliverable at the matching service tier.

## Samples

1. `01-clarity-call-sample.md` - $47 Tattoo Clarity Call / one-page Clarity Recap
2. `02-tattoo-blueprint-sample.md` - $99 Tattoo Blueprint / client Blueprint + one-page Artist Brief
3. `03-major-project-blueprint-sample.md` - $250 Major Project Blueprint / expanded client roadmap + one-page Artist Brief

## Landing-page use

The $99 sample should be the primary public example because it represents the core offer. Show enough of the original messy intake to make the value obvious, then show the polished client Blueprint and Artist Brief.

The visual PDF versions should be used for previews/downloads. The Markdown files are the canonical content source.
