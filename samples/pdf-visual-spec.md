# Sample PDF Visual Specification

The customer-facing PDFs should feel like an experienced tattoo professional's project notes that have been cleaned up and made useful - not a corporate consulting deck and not a generic AI report.

## Visual direction

- white / warm ivory paper base
- near-black body text
- dark oxblood section labels and headings
- thin structural rules
- strong editorial typography
- generous white space
- light warm-gray callout blocks
- no stock tattoo imagery inside the deliverable
- no fake blueprints, measuring grids, gears, skull decorations, or tattoo-shop clip art

## Header

Left: `TATTOO BLUEPRINT` in small oxblood caps.  
Right: `TATTOO BLUEPRINT / SAMPLE` on public fictional examples only.

## Title block

Large deliverable name, then client name / document purpose beneath it.

Examples:
- `Tattoo Clarity Recap`
- `Tattoo Blueprint`
- `Major Project Blueprint`
- `Artist Intent Brief`

## Information architecture

Use callout boxes only for information that benefits from being scanned quickly:
- starting point
- emotional target
- must keep / can change
- reminders
- artist collaboration note

Do not put every section in a box.

## Artist Intent Brief

Always optimize for one printed page whenever possible. The artist should be able to understand:
- core intent
- primary subjects
- non-negotiables
- creative freedom
- avoid list
- unresolved questions

without reading the longer client document.

## Public sample footer

`Fictional sample for demonstration. Final tattoo design and execution remain with the client's chosen tattoo artist.`

Real client deliverables should not say `SAMPLE` and should use the standard client-service footer instead.
