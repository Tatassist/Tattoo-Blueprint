# Tattoo Blueprint by Joker Ink

Internal operating system for the Tattoo Blueprint client-side tattoo planning service.

## Launch offers
- Tattoo Clarity Call — $47
- Tattoo Blueprint — $99 (core offer)
- Major Project Blueprint — $250

## Operating principle
The product is Joker's conversation, tattoo judgment, and ability to draw useful information out of clients. The written brief is the handoff artifact. The executing tattoo artist retains final design, tattooability, technical, and execution control.
